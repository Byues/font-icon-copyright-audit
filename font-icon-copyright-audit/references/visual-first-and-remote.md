# 图片先行检索与 CDR 远程审查

## 图片先行的含义

先从真实画面找到要核查的产品、成品区域、文字和图标，再从结构及授权核实。用户希望尽量多格式，按实际环境尝试支持，不能把“列入处理路径”说成“该环境已具备全部解析能力”。

1. 清点全部源文件，保留哈希与类型。先收集已有真实预览、图片、PDF 页面和可信工作副本渲染；为多页／多帧文件建立页／帧对应。
2. 生成本地联系表，先找包装本体、标签、说明书正文、彩页、字标与特殊图标。记录区域、坐标、文字内容及原件关系；成品外尺寸、色值和字体说明保留为排除项。
3. 用本地 OCR 或可用视觉工具检索文字、产品名、重复素材和图标位置。字体形似只产生候选及比对依据，不能直接确定字体或给侵权结论。不能凭 OCR 字体、PDF OCR 层或浏览器回退字体确认原设计用字。
4. 对每个候选回到源文件的文字对象、PDF 字体资源与实际文本、OOXML 运行段等核实。图像哈希相同可复用定位结果，主体、渠道和授权不能自动复用。
5. 保存“图像定位证据”和“字体技术确认依据”两个来源。无法恢复原字体的转曲／图片项目维持待核查，不因能看见文字就标技术确认。

## 常见格式处理路径

| 文件 | 先取得的画面 | 后续核实与限制 |
|---|---|---|
| PDF | 逐页真实渲染；加密、坏页、超限逐件记 | 字体对象、嵌入／子集、实际可见文本与坐标；扫描页图片文字仍待原字体 |
| JPG/JPEG/PNG/BMP/WEBP | 原图及可读缩略图 | 定位／OCR，找可编辑源文件，不以图片定字库 |
| TIF/TIFF/GIF | 每页／每帧及原始尺寸、帧编号 | 多帧不能只看首帧就声称全部完成 |
| AVIF/HEIC/HEIF/ICO及其他图片 | 当前 Pillow/系统正规解码器能读则出图 | 解码器缺失登记，不假称全部支持，也不擅自联网转换 |
| CDR | 原文件内嵌预览先定位；再远程 CorelDRAW 导出真实页面 | 预览可能低清／过时；全页原生对象、替代提示与原字体分别核实 |
| AI/EPS/SVG | 可信内嵌／兼容 PDF 或正规应用渲染 | 未经检查不运行 SVG 脚本、远程引用或不可信 PostScript；文字／路径分开 |
| PSD/PSB | 合成预览或正规 Photoshop 工作副本渲染 | 文字图层字体／范围另取；扁平预览不证明图层字体 |
| INDD/IDML | 已有 PDF／可信应用导出 | 故事文本与样式继承、缺失字体和链接资源另核 |
| DOC/DOCX/XLS/XLSX/PPT/PPTX | 已有预览或正规本地办公软件工作副本导出 | 主题／样式／母版和实际运行段，转换替代不能冒充原字体 |
| HTML/CSS/网页备份 | 在不执行不可信脚本／不上传资料前提下的可用画面 | 实际字体加载、系统后备、默认字体和第三方资源分开 |
| ZIP/RAR/7Z | 安全读取成员后按其实际类型处理 | 成员清单、嵌套、限额、加密／缺分卷与未覆盖单独记录 |
| 视频与其他格式 | 用户纳入时用已有本地工具提取实际字幕／关键帧 | 声明采样范围，不将关键帧抽样说成逐帧全量；字幕样式与烧录文字分开 |

`scripts/prepare_visuals.py` 是 PDF／位图联系表辅助工具。它不能打开 CDR／Adobe／办公源文件，也不做 OCR；由可用正规应用导出后再交图像流程。它不把未支持项从清单中删掉。任何页数限制必须在覆盖说明中披露。

## CDR 必须走远程桌面的工作方式

本用户的 CorelDRAW 在企业远程桌面环境。处理 CDR 时优先查找已有已授权 RDP 会话并复用；没有会话则用用户明确的企业目的地启动远程桌面。不要将本机缺少 CorelDRAW 当作最终放弃，也不要谎称存在本机后台接口。

- 目的地、设备和本批资料授权从当前用户上下文取得。已授权同一企业电脑及同批材料可继续复制粘贴工作副本，不重复要求确认。不得把过去某公司／某设备的传输批准扩展给其他公司、其他设备或第三方识别平台。
- 优先已连接会话和正常企业登录方式。需输入新口令、验证码或处理认证安全提示时按工具要求交用户完成；不在技能、脚本、日志、截图说明或命令参数中保存凭据，不绕过安全警告。
- 使用当前可用的 computer-use 技能和正规接口；UI 工具不支持或中止时遵守其限制，不用未授权渠道绕过。浏览器权限不是 CDR 审查的必要条件；仅网页视觉测试需要浏览器。
- 只复制本批必要工作副本至远程新建审查目录，核对传输数量／大小／哈希；保留本地和远程路径映射。源文件不移动、不覆盖、不改名。字体文件不能因缺字而擅自复制、安装或分发。
- 在远程 CorelDRAW 打开工作副本，记录打开结果、版本、页数、缺失／替代字体提示、图层、文字对象、实际字体读取名和坐标；保存真实页面截图／导出、对象数据和错误。保持未保存关闭，不能“另存覆盖”原件或工作副本来掩盖替代。
- 原文件字体声明和打开后的字体名独立保存。明确是替代目标的名称不确认原设计字体；原关系不明则保留缺口。低清预览或图像候选不能补成原生对象证据。
- 回传真实元数据、图像及日志，核对证据文件能读和路径有效。原件在使用应用／副本流程前后核对 SHA-256；不影响用户其他会话、文件和未保存工作。

## 远程暂不可用

继续可独立执行的本地 PDF／图片预览、清点和授权资料核查。CDR 可先登记内嵌预览／可解析声明，但状态写“远程原生审查未完成”，逐文件说明缺少的对象字体、页图和替代核验。不要用缩略图或本地解析成功替代远程审阅完成。
