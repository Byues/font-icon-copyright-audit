# 授权核对与证据边界

## 两个独立结论

“侵权核查状态”使用以下六种值。合规风险与内部优先级另列，不以颜色替代证据。

| 状态 | 使用条件 |
|---|---|
| 已确认存在授权缺口 | 实际使用与权利有证据，完整授权核查后发现具体用途／主体／期限等缺口；法律定性仍待法务 |
| 疑似未授权 | 字体及场景确认，已检索相关授权材料，未找到覆盖实际用途的有效证明；不能因此断言未购买 |
| 授权待核实 | 字体已识别，但合同、权利人、许可解释或覆盖范围缺证 |
| 证据不足 | 原字体、实际位置或发布场景尚不能可靠确认 |
| 已核实授权覆盖 | 有对应字体、版本及实际用途的有效许可或其他依据 |
| 不适用 | 没有范围内相关字体／图标事项；排除项不计实际使用 |

| 风险 | 依据 |
|---|---|
| 严重风险 | 确认实际使用及具体许可缺口，完成授权材料核对，立即交法务 |
| 高风险 | 特定受限字体的重要商业使用且许可不明，或用户明示的内部字库优先级；后者明确标注“内部规则” |
| 中风险 | 字体／用途识别，仍需补授权证据或解释，影响相对有限 |
| 低风险 | 可复核许可证／有效授权与实际用途一致；不能因“开源”“系统自带”名称直接归低 |
| 待核查 | 原字体、位置或关键证据不足，不混入低风险 |

强制字库高优先级时，即使授权已覆盖，也保留覆盖状态，说明内部排序。不要为了颜色要求把授权已核实改为疑似未授权。原关系不明且读取名命中时，高风险注明替代可能，状态仍为证据不足。已知读取名是软件替代目标（font_read_role=substitute 或 substitution_status=confirmed）时，不能凭替代目标断言原成品用字，列待核查、优先恢复原字体。候选字库别名需核实归属再启用字库规则。具体严重风险优先于内部高风险标签。

## A–D 技术证据与授权证据分开

- A：原文件或技术元数据确认字体。明确确认对象是字体声明、文字对象还是字体文件版本；资源表名称不直接确认可见文字。
- B：高可信轮廓样本比对及依据，缺少技术证据；普通视觉近似不能算 B，也不能写确定字体名。
- C：实际画面／渠道可确认，原字体不明，包括图片、转曲或替代关系不清。
- D：仅有文件、品牌、产品或发布线索。

独立授权字段记录证据路径、条款出处、主体、渠道、时间、覆盖／缺口与核对人。A 级字体证据不等于侵权事实；版本和授权允许未知。

## 授权材料与公开资料

核查输入范围中所有合同、证书、采购及订单、发票、附件、外包协议及源文件交付条款；全文无法读取则列缺口。目录名“免费字体”、安装清单、设计方说法和内嵌 copyright／license 字段不替代实际许可。

逐项核对字体家族、字重、内部名和版本；完整字体哈希与嵌入子集流哈希分开。确认权利人、授权链、购买／使用／品牌／发布主体。分别匹配桌面编辑、静态对外成果、商标长期使用、包装、广告、Webfont、应用／文档嵌入、字体分发。核查有效期、许可取得时点、实际发布时间和历史条款。外包设计公司的字体使用权限不自动覆盖客户最终发布。

优先官方说明、对应字体许可证、厂商产品页及原始合同。当前网页不证明历史条款，通用 FAQ 不证明企业已购。保存网址、标题、核验日期、适用版本、解释与局限；未核实资料标待核实。不编造价格、合同、厂商答复和法律结论。

Microsoft、Adobe Fonts、开源字体均按实际用途核对，不能将软件可见、预装或“免费”视为任意复制／嵌入／分发。开源要核对版本、许可证及改名／分发条件。医疗标准符号的标准版本、符号对应及具体素材来源分别核对。

## 二次复核

严重／高风险逐项检查：字体替代、未使用资源和设计说明、是否成品内、同名异版、实际外部发布与发布主体、遗漏授权及条款误读。保留复核记录；未完整授权核查不能标已确认缺口。
