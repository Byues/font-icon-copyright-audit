# 技术提取与证据边界

仅在处理对应格式时读取本参考。先保留原始名称、原始位置与提取方法，再生成用于检索的规范名称。解析成功、确认字体名称、确认实际可见使用、核实授权是四个不同结果，分别记录。

## 通用证据

每个文件登记唯一编号、相对路径、实际容器、大小、SHA-256、检测状态及失败原因；每条使用记录关联文件编号、页／对象／坐标、字体原名、内部名、版本（未知则直写未知）、证据等级、授权核查证据与局限。重复内容保留全部路径，按哈希复用解析结果，不能据此合并业务渠道或授权主体。

截图保存原页或原图及可追溯区域，注明来源哈希、页码、坐标和提取方式。红框用于定位文字，不表示已认定侵权；文字替换或重绘不能充当原件截图。JSON 是机器可读的提取结果与索引，**不是截图，也不是授权证明**；同步提供能直接打开的 HTML 图文索引或 UTF-8 TXT 说明，将编号链接到真实 PNG／JPG、原页与元数据。不要要求用户把 JSON 当 PDF 打开。

## PDF

- 遍历页面字体资源与嵌套 Form XObject，记录字体对象号、BaseFont／PostScript 名称、子集前缀、字体类型、嵌入状态与可获取的版本。文件内嵌字体流的哈希与完整字体文件哈希分开记录。
- 资源字典中有某字体，只能确认资源声明。继续核对内容流的字体选择、实际文本运行段、页面坐标与渲染结果；未使用资源不能计为实际用字。隐藏、裁剪、不可见文本或 OCR 层应单独标记，不能自动等同可见成品文字。
- 提取不到文本不代表没有文字。渲染后区分路径化、图片化和无文字页面；转曲标为“轮廓化文字，原字体待确认”。字体映射缺失、乱码、损坏和受限读取如实登记。
- 导出时可能有字体替代；不能拿当前机器安装字体或渲染替代字体填作原文件字体。

## Word／Excel／PowerPoint

识别 OOXML 实际容器，沿关系文件定位正文、页眉页脚、表格、工作表、共享字符串、富文本、幻灯片、母版、版式、图表及嵌入对象。只解读数据，不执行宏、不刷新外部链接。

运行段的显式字体优先；缺少显式设置时解析段落／字符样式、继承链、文档默认值、主题字体及语言映射，记录字体是显式、继承还是候选回退。Excel 同时核对单元格样式索引和富文本运行段；PowerPoint 同时核对运行段、段落默认、占位符、版式与母版。保留段落／表格／单元格／幻灯片及对象位置。未被文本引用的样式或主题字体单列为声明，不计实际使用。自动分页无法稳定复现时用结构位置，不编造页码。

旧版 DOC／XLS 等可尝试现有正规本机接口或经授权的工作副本转换；记录原格式、软件版本、转换与替换情况，不能把转换后字体当原始字体技术确认。无法解析的对象或嵌入文件逐件列为未覆盖。

## CorelDRAW（CDR）

- 原件只读，先计算哈希。按本用户环境启动／复用已授权远程桌面，在企业远程电脑的 CorelDRAW 正规接口检查工作副本；遵循 [visual-first-and-remote.md](visual-first-and-remote.md) 的远程流程。用户本次明确另有本机 CorelDRAW 时才按新环境调整。阻止保存回原件，保留应用版本、打开状态、缺字／替换提示与日志。未取得原生接口时可读取 ZIP／RIFF 元数据，但须明确远程对象审查未完成。
- 分别保存“原文件声明字体”和“软件打开后文字对象读取字体”。文件级 FontsUsed／字体表不能证明某个具体对象使用了该字体；只有对象与位置建立对应后才能形成使用记录。
- 打开后对象可能反映替代字体。记录对象路径／ID、页、图层、文本范围、原始文本及边界框；原始声明与对象名称不一致时保留两者并标“原字体或替代关系待核实”。例如原文件 3.0、打开后 2.0，不能视为同一版本，也不能用本机安装版本补齐。
- 依据可见成品区域筛选包装、标签、说明书正文和彩页；成品外尺寸、色值、字体说明与设计备注单独排除并保留排除理由。对象跨界或范围不能判断时进入人工复核。轮廓、位图与未恢复的旧对象不能伪装成已确认文字对象。

## 其他设计与网页格式

| 格式 | 提取要点与边界 |
|---|---|
| AI／EPS | 优先原始文字对象、字体引用、PostScript 名称与可解析元数据；有可读 PDF 兼容部分时注明来自兼容部分。转曲路径只能登记轮廓，不能凭外形定名字。 |
| SVG／HTML／CSS | 同时记录 text／tspan／样式继承、font-family 候选列表、@font-face 资源与实际文字使用关系。声明、实际加载、系统后备、浏览器默认及第三方资源分开；脚本动态结果无法获得时披露限制。SVG path 不是字体确认。 |
| PSD／PSB | 通过支持的文字图层接口读取字体、文本范围、图层路径和坐标。合成图、图层缩略图与不可读文字描述不能替代文字图层证据。 |
| INDD／IDML | 优先正规本机接口或结构化 IDML 的故事、文本范围与样式继承；软件转换、缺失字体与链接资源单列。没有可用解析方法则保留格式缺口。 |

工具不支持、软件缺失、接口失败或文件损坏时，保留已经取得的证据并逐件登记未覆盖范围；不强制安装系统级软件，不默认获准调用外网识别服务或传输内部文件。

## 图片、字体与压缩包

**图片／OCR：**登记原图尺寸、文字区域、坐标和截图。本地 OCR 只辅助发现、转录与定位文字；OCR 文字结果不能识别原字体。视觉样本比对需保存比对依据并标候选，不能升级为技术确认。无法逐图复核时说明实际覆盖数。

**字体文件：**提取字体族名、子族名、PostScript 名、版本、版权、许可字段与 SHA-256。嵌入许可位或内部声明只能说明文件元数据，不能替代公司的合同、许可主体、采购记录或特定渠道授权。未经授权不要提取并另存可复用字体文件，不把字体文件放入对外证据包。

**压缩包：**先列目录再读取成员。拒绝绝对路径、盘符／网络路径、含父级穿越的路径及符号／硬链接；解析规范化后的目标必须仍位于本次输出目录。拒绝执行成员。嵌套最多五层，单成员展开最多 1 GiB，单包累计展开最多 10 GiB，并按实际读取字节执行限制。记录压缩包路径、成员路径、层级、大小、哈希和读取状态；加密、缺分卷、损坏、超限、路径不安全及不支持的格式逐件登记。成员数量与外部原始文件数量分开统计。字体成员仅在内存中读取元数据和哈希，不另存字体。

## 图标与标准符号

图标字体、矢量素材、位图素材及标准符号建立独立使用记录，不混入独立文字字体数量。记录图标来源、版本、素材／字形标识、出现位置、许可或标准依据。医疗器械标准符号应分别核对采用标准及版本、符号含义对应关系、实际图形素材来源与可用依据；不能仅因出现 ISO 等标准符号就推定侵权，也不能据此默认任意图库绘制版本均可使用。
